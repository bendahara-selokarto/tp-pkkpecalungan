# Profil Menu Pengguna: Peran Pokja I Desa

Dokumen ini mencatat daftar menu dan hak akses untuk pengguna dengan peran **desa-pokja-i** dalam aplikasi TP-PKK Pecalungan.

## Informasi Dasar
- **Role**: `desa-pokja-i`
- **Level**: Desa
- **Fokus**: Penghayatan dan Pengamalan Pancasila, Gotong Royong.

## Daftar Menu dan Hak Akses

### 1. Navigasi Utama (Top Bar)
| Menu | Deskripsi |
| :--- | :--- |
| **Dashboard** | Statistik grafik kegiatan Pokja I tingkat desa. |
| **Arsip** | Pengelolaan dokumen digital terkait Pokja I desa. |
| **Profil** | Pengaturan informasi akun. |

### 2. Menu Domain (Sidebar)

#### **A. Kelompok Pokja I (Hak Akses: Read-Write)**
- **Buku Program Kerja TP PKK**: Perencanaan program kerja Pokja I desa.
- **Buku Data Kegiatan Pokja I**: Laporan ringkasan data kegiatan (Format 4.21).
- **Buku Kegiatan, Prestasi, Bantuan, Inventaris**.
- **Buku Kader Khusus, Simulasi Penyuluhan, BKR, Anggota Pokja, PAAR**.

#### **B. Modul Tambahan/Audit (Hak Akses: Read-Only)**
User desa Pokja I memiliki akses baca untuk modul umum guna sinkronisasi data:
- Buku Daftar Hadir, Buku Tamu, Buku Keuangan.
- Data Warga & Kegiatan Warga.
- BKL, Taman Bacaan, Koperasi, Kejar Paket, Literasi Warga.
- Pilot Project Keluarga Sehat & Naskah Pelaporan.

### 3. Fitur Pelaporan & Cetak
- **Laporan PDF Khusus**: Menu cepat untuk Format 4.21.
