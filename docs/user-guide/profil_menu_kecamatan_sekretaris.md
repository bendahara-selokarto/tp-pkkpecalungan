## Informasi Dasar
- **Email**: `kecamatan.sekretaris.pecalungan@gmail.com`
- **Role**: `kecamatan-sekretaris`
- **Level**: Kecamatan

## Daftar Menu dan Hak Akses

### 1. Navigasi Utama (Top Bar)
| Menu | Deskripsi |
| :--- | :--- |
| **Dashboard** | Visualisasi statistik kegiatan dan cakupan dokumen. |
| **Arsip** | Pengelolaan dokumen digital (Upload, Download, Hapus). |
| **Profil** | Pengaturan informasi akun dan keamanan. |

### 2. Menu Domain (Sidebar)

#### **A. Sekretaris PKK (Hak Akses: Read-Write)**
Ini adalah modul operasional utama bagi sekretaris kecamatan:
- Daftar Anggota Tim Penggerak PKK
- Agenda Surat Masuk/Keluar
- Buku Inventaris (4.12)
- Buku Kegiatan
- Buku Notulen Rapat
- Buku Prestasi
- Buku Bantuan
- Buku Kader Khusus

#### **B. Penunjang Buku Wajib (Hak Akses: Read-Write)**
- Data Umum (Laporan PDF Data Umum Kecamatan)
- Program Kerja

#### **C. Monitoring Kecamatan (Hak Akses: Read-Only)**
Menu untuk pengawasan aktivitas di tingkat desa:
- **Rekap Kegiatan Desa**: Memantau seluruh input kegiatan dari desa-desa di bawah wilayah kecamatan.
- **Rekap Arsip Desa**: Memantau dokumen arsip yang diunggah oleh user desa.

#### **D. Kelompok Pokja (Hak Akses: Read-Only)**
Sekretaris memiliki visibilitas terhadap data Pokja untuk keperluan koordinasi:
- **Pokja I**: Program Kerja, Data Kegiatan Pokja I, Simulasi Penyuluhan, BKR, PAAR, dll.
- **Pokja II**: Program Kerja, Data Kegiatan Pokja II, Rekap Kelompok UP2K, dll.
- **Pokja III**: Program Kerja, Data Kegiatan Pokja III, Rumah Sehat, Pemanfaatan Tanah Pekarangan, Industri Rumah Tangga, dll.
- **Pokja IV**: Program Kerja, Data Kegiatan Pokja IV, Hasil Kegiatan Posyandu, dll.

#### **E. Modul Tambahan/Audit (Hak Akses: Read-Only)**
- Buku Daftar Hadir & Buku Tamu
- Buku Keuangan
- Laporan Tahunan PKK
- Data Warga & Kegiatan Warga
- BKL, Taman Bacaan, Koperasi, Kejar Paket, Literasi Warga
- Pilot Project Keluarga Sehat & Naskah Pelaporan

### 3. Fitur Pelaporan
- **Cetak Lampiran**: Akses ke berbagai format laporan standar (4.9a, 4.10, 4.12, 4.13, 4.14, 4.21-4.24, dll).
- **Grafik Dashboard**: Cetak ringkasan statistik dalam format PDF.
