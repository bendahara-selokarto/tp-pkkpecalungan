# Profil Menu Pengguna: Peran Pokja IV Desa

Dokumen ini mencatat daftar menu dan hak akses untuk pengguna dengan peran **desa-pokja-iv** dalam aplikasi TP-PKK Pecalungan.

## Informasi Dasar
- **Role**: `desa-pokja-iv`
- **Level**: Desa
- **Fokus**: Kesehatan, Kelestarian Lingkungan Hidup, dan Perencanaan Sehat.

## Daftar Menu dan Hak Akses

### 1. Navigasi Utama (Top Bar)
| Menu | Deskripsi |
| :--- | :--- |
| **Dashboard** | Statistik grafik kegiatan Pokja IV tingkat desa. |
| **Arsip** | Pengelolaan dokumen digital terkait Pokja IV desa. |
| **Profil** | Pengaturan informasi akun. |

### 2. Menu Domain (Sidebar)

#### **A. Kelompok Pokja IV (Hak Akses: Read-Write)**
- **Buku Program Kerja TP PKK**: Perencanaan program kerja Pokja IV desa.
- **Buku Data Kegiatan Pokja IV**: Laporan ringkasan data kegiatan (Format 4.24).
- **Buku Kegiatan, Prestasi, Bantuan, Kader Khusus, Inventaris**.
- **Hasil Kegiatan Posyandu**: (Format 4.14.4e).

#### **B. Modul Tambahan/Audit (Hak Akses: Read-Only)**
User desa Pokja IV memiliki akses baca untuk modul umum:
- Buku Daftar Hadir, Buku Tamu, Buku Keuangan, Laporan Tahunan.
- Data Warga, Kegiatan Warga.
- Pilot Project Keluarga Sehat & Naskah Pelaporan.

### 3. Fitur Pelaporan & Cetak
- **Laporan PDF Khusus**: Menu cepat untuk Format 4.24.
