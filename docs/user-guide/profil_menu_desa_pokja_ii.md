# Profil Menu Pengguna: Peran Pokja II Desa

Dokumen ini mencatat daftar menu dan hak akses untuk pengguna dengan peran **desa-pokja-ii** dalam aplikasi TP-PKK Pecalungan.

## Informasi Dasar
- **Role**: `desa-pokja-ii`
- **Level**: Desa
- **Fokus**: Pendidikan dan Keterampilan, Pengembangan Kehidupan Berkoperasi.

## Daftar Menu dan Hak Akses

### 1. Navigasi Utama (Top Bar)
| Menu | Deskripsi |
| :--- | :--- |
| **Dashboard** | Statistik grafik kegiatan Pokja II tingkat desa. |
| **Arsip** | Pengelolaan dokumen digital terkait Pokja II desa. |
| **Profil** | Pengaturan informasi akun. |

### 2. Menu Domain (Sidebar)

#### **A. Kelompok Pokja II (Hak Akses: Read-Write)**
- **Buku Program Kerja TP PKK**: Perencanaan program kerja Pokja II desa.
- **Buku Data Kegiatan Pokja II**: Laporan ringkasan data kegiatan (Format 4.22).
- **Buku Kegiatan, Prestasi, Bantuan, Inventaris, Kader Khusus**.
- **Buku Rekap Kelompok UP2K**: Rekapitulasi UP2K desa.

#### **B. Modul Tambahan/Audit (Hak Akses: Read-Only)**
User desa Pokja II memiliki akses baca untuk modul umum:
- Buku Daftar Hadir, Buku Tamu, Buku Keuangan, Laporan Tahunan.
- Data Warga, Kegiatan Warga, Kejar Paket, Taman Bacaan, Koperasi.
- Literasi Warga, BKB Kegiatan, Tutor Khusus, Pelatihan Kader.

### 3. Fitur Pelaporan & Cetak
- **Laporan PDF Khusus**: Menu cepat untuk Format 4.22.
