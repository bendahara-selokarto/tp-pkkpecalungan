# Profil Menu Pengguna: Peran Pokja III Kecamatan

Dokumen ini mencatat daftar menu dan hak akses untuk pengguna dengan peran **kecamatan-pokja-iii** dalam aplikasi TP-PKK Pecalungan.

## Informasi Dasar
- **Role**: `kecamatan-pokja-iii`
- **Level**: Kecamatan
- **Fokus**: Pangan, Sandang, Perumahan, dan Tata Laksana Rumah Tangga.

## Daftar Menu dan Hak Akses

### 1. Navigasi Utama (Top Bar)
| Menu | Deskripsi |
| :--- | :--- |
| **Dashboard** | Statistik grafik kegiatan dan capaian khusus Pokja III. |
| **Arsip** | Pengelolaan dokumen digital terkait Pokja III. |
| **Profil** | Pengaturan informasi akun. |

### 2. Menu Domain (Sidebar)

#### **Kelompok Pokja III (Hak Akses: Read-Write)**
User memiliki akses penuh untuk mengelola data operasional Pokja III:
- **Buku Program Kerja TP PKK**: Perencanaan program kerja Pokja III.
- **Buku Data Kegiatan Pokja III**: Laporan ringkasan data kegiatan (Format 4.23).
- **Buku Kegiatan**: Catatan aktivitas harian/periodik Pokja III.
- **Buku Prestasi**: Catatan penghargaan atau keberhasilan lomba di bidang pangan/perumahan.
- **Buku Bantuan**: Data bantuan yang dikelola atau disalurkan melalui Pokja III.
- **Buku Inventaris**: Daftar sarana dan prasarana milik Pokja III.
- **Buku Kader Khusus**: Pendataan kader spesifik (misal: Kader Hatinya PKK).
- **Buku Rumah Sehat dan Tidak Sehat**: Pendataan kondisi perumahan (Format 4.14.2a).
- **Buku HATINYA PKK**: pemanfaatan tanah pekarangan (Format 4.14.2b).
- **Buku Bantu Pangan**: entri bisnis autentik baru untuk pemanfaatan pekarangan dan pangan keluarga.
- **Buku Jumlah Industri Rumah Tangga**: Pendataan industri kecil keluarga (Format 4.14.2c).

### 3. Fitur Pelaporan & Cetak
- **Laporan PDF Khusus**: Menu cepat untuk menghasilkan laporan rekapitulasi Pokja III (4.23).
