# Profil Menu Pengguna: Peran Sekretaris Desa

Dokumen ini mencatat daftar menu dan hak akses untuk pengguna dengan peran **desa-sekretaris** dalam aplikasi TP-PKK Pecalungan.

## Informasi Dasar
- **Role**: `desa-sekretaris`
- **Level**: Desa
- **Fokus**: Administrasi Umum dan Koordinasi Seluruh Pokja Desa.

## Daftar Menu dan Hak Akses

### 1. Navigasi Utama (Top Bar)
| Menu | Deskripsi |
| :--- | :--- |
| **Dashboard** | Statistik grafik kegiatan dan cakupan dokumen tingkat desa. |
| **Arsip** | Pengelolaan dokumen digital milik desa. |
| **Profil** | Pengaturan informasi akun. |

### 2. Menu Domain (Sidebar)

#### **A. Sekretaris PKK (Hak Akses: Read-Write)**
- Daftar Anggota Tim Penggerak PKK
- Agenda Surat Masuk/Keluar
- Buku Inventaris (4.12)
- Buku Kegiatan
- Buku Notulen Rapat
- Buku Prestasi
- Buku Bantuan

#### **B. Penunjang Buku Wajib (Hak Akses: Read-Write)**
- **Data Umum**: Laporan rekapitulasi data umum desa.
- **Program Kerja**: Pengelolaan rencana program kerja desa.

#### **C. Kelompok Pokja I, II, III, IV (Hak Akses: Read-Only)**
Sekretaris memiliki hak untuk memantau (view) seluruh data yang diinput oleh masing-masing Pokja di tingkat desa untuk keperluan koordinasi dan pelaporan.

#### **D. Modul Tambahan/Audit (Hak Akses: Read-Only)**
- Buku Daftar Hadir & Buku Tamu
- Buku Keuangan
- Laporan Tahunan PKK
- Data Warga & Kegiatan Warga
- BKL, Taman Bacaan, Koperasi, Kejar Paket, Literasi Warga
- Pilot Project Keluarga Sehat & Naskah Pelaporan

### 3. Fitur Pelaporan & Cetak
- **Grafik Dashboard**: Cetak ringkasan statistik dalam format PDF.
