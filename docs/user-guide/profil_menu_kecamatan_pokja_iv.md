# Profil Menu Pengguna: Peran Pokja IV Kecamatan

Dokumen ini mencatat daftar menu dan hak akses untuk pengguna dengan peran **kecamatan-pokja-iv** dalam aplikasi TP-PKK Pecalungan.

## Informasi Dasar
- **Role**: `kecamatan-pokja-iv`
- **Level**: Kecamatan
- **Fokus**: Kesehatan, Kelestarian Lingkungan Hidup, dan Perencanaan Sehat.

## Daftar Menu dan Hak Akses

### 1. Navigasi Utama (Top Bar)
| Menu | Deskripsi |
| :--- | :--- |
| **Dashboard** | Statistik grafik kegiatan dan capaian khusus Pokja IV. |
| **Arsip** | Pengelolaan dokumen digital terkait Pokja IV. |
| **Profil** | Pengaturan informasi akun. |

### 2. Menu Domain (Sidebar)

#### **Kelompok Pokja IV (Hak Akses: Read-Write)**
User memiliki akses penuh untuk mengelola data operasional Pokja IV:
- **Buku Program Kerja TP PKK**: Perencanaan program kerja Pokja IV.
- **Buku Data Kegiatan Pokja IV**: Laporan ringkasan data kegiatan (Format 4.24).
- **Buku Kegiatan**: Catatan aktivitas harian/periodik Pokja IV.
- **Buku Prestasi**: Catatan penghargaan atau keberhasilan lomba di bidang kesehatan/lingkungan.
- **Buku Bantuan**: Data bantuan yang dikelola atau disalurkan melalui Pokja IV.
- **Buku Kader Khusus**: Pendataan kader spesifik (misal: Kader Posyandu, Kader PHBS).
- **Data Umum Pokja IV**: Laporan data umum bidang kesehatan (Format 4.20a).
- **Hasil Kegiatan Posyandu**: Pendataan hasil kegiatan posyandu (Format 4.14.4e).

### 3. Fitur Pelaporan & Cetak
- **Cetak Lampiran**: Akses cetak untuk buku-buku di atas dalam format PDF standar.
- **Laporan PDF Khusus**: Menu cepat untuk menghasilkan laporan rekapitulasi Pokja IV (4.24) dan Data Umum (4.20a).
