# Profil Menu Pengguna: Peran Pokja II Kecamatan

Dokumen ini mencatat daftar menu dan hak akses untuk pengguna dengan peran **kecamatan-pokja-ii** dalam aplikasi TP-PKK Pecalungan.

## Informasi Dasar
- **Role**: `kecamatan-pokja-ii`
- **Level**: Kecamatan
- **Fokus**: Pendidikan dan Keterampilan, Pengembangan Kehidupan Berkoperasi.

## Daftar Menu dan Hak Akses

### 1. Navigasi Utama (Top Bar)
| Menu | Deskripsi |
| :--- | :--- |
| **Dashboard** | Statistik grafik kegiatan dan capaian khusus Pokja II. |
| **Arsip** | Pengelolaan dokumen digital terkait Pokja II. |
| **Profil** | Pengaturan informasi akun. |

### 2. Menu Domain (Sidebar)

#### **Kelompok Pokja II (Hak Akses: Read-Write)**
User memiliki akses penuh untuk mengelola data operasional Pokja II:
- **Buku Program Kerja TP PKK**: Perencanaan program kerja Pokja II.
- **Buku Data Kegiatan Pokja II**: Laporan ringkasan data kegiatan (Format 4.22).
- **Buku Kegiatan**: Catatan aktivitas harian/periodik Pokja II.
- **Buku Prestasi**: Catatan penghargaan atau keberhasilan lomba di bidang pendidikan/ekonomi.
- **Buku Bantuan**: Data bantuan yang dikelola atau disalurkan melalui Pokja II.
- **Buku Inventaris**: Daftar sarana dan prasarana milik Pokja II.
- **Buku Kader Khusus**: Pendataan kader spesifik (misal: Kader UP2K, Tutor PAUD).
- **Buku Rekap Kelompok UP2K**: Rekapitulasi Usaha Peningkatan Pendapatan Keluarga.

### 3. Fitur Pelaporan & Cetak
- **Laporan PDF Khusus**: Menu cepat untuk menghasilkan laporan rekapitulasi Pokja II (4.22).

---
*Catatan: Peran Pokja II Kecamatan saat ini hanya mengelola modul di dalam grup Pokja II. Akses terhadap modul pendidikan umum (seperti Kejar Paket atau Taman Bacaan) biasanya berada di bawah koordinasi Sekretaris atau peran yang memiliki grup 'Belum Ada Pemilik'.*
