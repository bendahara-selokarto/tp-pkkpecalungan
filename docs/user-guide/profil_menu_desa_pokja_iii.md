# Profil Menu Pengguna: Peran Pokja III Desa

Dokumen ini mencatat daftar menu dan hak akses untuk pengguna dengan peran **desa-pokja-iii** dalam aplikasi TP-PKK Pecalungan.

## Informasi Dasar
- **Role**: `desa-pokja-iii`
- **Level**: Desa
- **Fokus**: Pangan, Sandang, Perumahan, dan Tata Laksana Rumah Tangga.

## Daftar Menu dan Hak Akses

### 1. Navigasi Utama (Top Bar)
| Menu | Deskripsi |
| :--- | :--- |
| **Dashboard** | Statistik grafik kegiatan Pokja III tingkat desa. |
| **Arsip** | Pengelolaan dokumen digital terkait Pokja III desa. |
| **Profil** | Pengaturan informasi akun. |

### 2. Menu Domain (Sidebar)

#### **A. Kelompok Pokja III (Hak Akses: Read-Write)**
- **Buku Program Kerja TP PKK**: Perencanaan program kerja Pokja III desa.
- **Buku Data Kegiatan Pokja III**: Laporan ringkasan data kegiatan (Format 4.23).
- **Buku Kegiatan, Prestasi, Bantuan, Kader Khusus, Inventaris**.
- **Buku Rumah Sehat dan Tidak Sehat**: (Format 4.14.2a).
- **Buku Bantu Pangan**: (Format 4.14.2b).
- **Buku Jumlah Industri Rumah Tangga**: (Format 4.14.2c).

#### **B. Modul Tambahan/Audit (Hak Akses: Read-Only)**
User desa Pokja III memiliki akses baca untuk modul umum:
- Buku Daftar Hadir, Buku Tamu, Buku Keuangan, Laporan Tahunan.
- Data Warga, Kegiatan Warga, Warung PKK.

### 3. Fitur Pelaporan & Cetak
- **Cetak Lampiran**: Akses cetak untuk buku laporan Pokja III tingkat desa.
- **Laporan PDF Khusus**: Menu cepat untuk Format 4.23.
