# Profil Menu Pengguna: Peran Pokja I Kecamatan

Dokumen ini mencatat daftar menu dan hak akses untuk pengguna dengan peran **kecamatan-pokja-i** dalam aplikasi TP-PKK Pecalungan.

## Informasi Dasar
- **Role**: `kecamatan-pokja-i`
- **Level**: Kecamatan
- **Fokus**: Penghayatan dan Pengamalan Pancasila, Gotong Royong.

## Daftar Menu dan Hak Akses

### 1. Navigasi Utama (Top Bar)
| Menu | Deskripsi |
| :--- | :--- |
| **Dashboard** | Statistik grafik kegiatan dan capaian khusus Pokja I. |
| **Arsip** | Pengelolaan dokumen digital terkait Pokja I. |
| **Profil** | Pengaturan informasi akun. |

### 2. Menu Domain (Sidebar)

#### **Kelompok Pokja I (Hak Akses: Read-Write)**
User memiliki akses penuh untuk mengelola data operasional Pokja I:
- **Buku Program Kerja TP PKK**: Perencanaan program kerja Pokja I.
- **Buku Data Kegiatan Pokja I**: Laporan ringkasan data kegiatan (Format 4.21).
- **Buku Kegiatan**: Catatan aktivitas harian/periodik Pokja I.
- **Buku Prestasi**: Catatan penghargaan atau keberhasilan lomba.
- **Buku Bantuan**: Data bantuan yang dikelola atau disalurkan.
- **Buku Inventaris**: Daftar sarana dan prasarana milik Pokja I.
- **Buku Kader Khusus**: Pendataan kader spesifik (misal: Kader PKBN, Kadarkum).
- **Buku Kegiatan Simulasi**: Pencatatan simulasi penyuluhan.
- **Buku Kegiatan BKR**: Bina Keluarga Remaja.
- **Buku Anggota Pokja I**: Daftar pengurus Pokja I tingkat kecamatan.
- **Buku Data PAAR**: Pola Asuh Anak dan Remaja.

### 3. Fitur Pelaporan & Cetak
- **Laporan PDF Khusus**: Menu cepat untuk menghasilkan laporan rekapitulasi Pokja I.

---
*Catatan: Berbeda dengan Sekretaris, peran Pokja I tidak memiliki akses ke menu monitoring desa secara global maupun menu administrasi umum (Buku Tamu/Keuangan).*
